ZUSTAND Studio – Kontaktaktualisierung

1. index.html, app.js und styles.css gemeinsam bei GitHub ersetzen.
2. Studio neu laden (Strg+F5).
3. Kandidaten > JSON importieren.
4. Zuerst kontakte_update_waldbestand.json importieren.
5. Dann kontakte_update_suesswasser.json importieren.
6. Das Studio erkennt vorhandene Kontakte und fragt vor der Aktualisierung nach.

Aktualisiert werden ausschließlich:
- Dienstl. E-Mail
- Dienstl. Telefon
- Dienstl. Postanschrift
- Offizielle Profil-/Kontaktseite

Unverändert bleiben:
- Gruppe
- Akquise-Status
- Anmoderation und Interviewfragen
- Z-Panel-Entwürfe

Datenschutz:
Die JSON-Dateien enthalten nur öffentlich bereitgestellte dienstliche Kontaktdaten.
